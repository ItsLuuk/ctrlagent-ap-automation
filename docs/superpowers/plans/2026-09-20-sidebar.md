# Sidebar Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace topbar with shadcn inset icon-collapsible sidebar in Shell.

**Architecture:** Rewrite only `src/components/ap/shell.tsx` to compose existing `src/components/ui/sidebar.tsx` as `SidebarProvider > Sidebar(variant=inset, collapsible=icon) + SidebarInset`. No routing changes, all 8 routes keep wrapping `<Shell>`.

**Tech Stack:** React 19, TanStack Router 1.170, shadcn sidebar (Radix Slot, Sheet, Tooltip), Tailwind 4, Bun, Vite 8

## Global Constraints

- Reuse `src/components/ui/sidebar.tsx` as-is — do NOT run `bunx shadcn add sidebar`, already installed.
- Single nav item only: Accounts Payable → `/` with `activeOptions={{exact:true}}`.
- Full replace — delete old `<header>` sticky topbar, no slim header保留.
- Preserve content width: inner wrapper `mx-auto max-w-[1400px] p-6`.
- Keep `prewarmVisionModel` useEffect in Shell.
- No new dependencies, no version bumps.
- Preserve `ProcessingBadge`, `UploadDialog`, avatar `LK` by moving to `SidebarFooter`.

- [ ] **Step 2: Replace component body with SidebarProvider layout**

```tsx
let warmed = false;

export function Shell({ children }: { children: ReactNode }) {
  useEffect(() => {
    if (warmed) return;
    warmed = true;
    void prewarmVisionModel();
  }, []);
  const pathname = useRouterState({ select: (s) => s.location.pathname });
  const isHome = pathname === "/";

  return (
    <SidebarProvider defaultOpen={true}>
      <Sidebar side="left" variant="inset" collapsible="icon">
        <SidebarHeader>
          <div className="flex items-center gap-2 px-2 py-1">
            <Link to="/" className="flex items-center gap-2.5">
              <span className="grid size-8 place-items-center rounded-lg bg-primary text-primary-foreground">
                <CircleDollarSign className="size-4" />
              </span>
              <span className="font-display text-base font-semibold tracking-tight group-data-[collapsible=icon]:hidden">
                Ledgerflow
              </span>
            </Link>
            <SidebarTrigger className="ml-auto" />
          </div>
        </SidebarHeader>
        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupContent>
              <SidebarMenu>
                <SidebarMenuItem>
                  <SidebarMenuButton asChild isActive={isHome} tooltip="Accounts Payable">
                    <Link to="/" activeOptions={{ exact: true }}>
                      <Inbox className="size-4" />
                      <span>Accounts Payable</span>
                    </Link>
                  </SidebarMenuButton>
                </SidebarMenuItem>
              </SidebarMenu>
            </SidebarGroupContent>
          </SidebarGroup>
        </SidebarContent>
        <SidebarFooter>
          <div className="flex flex-col gap-3 p-2">
            <ProcessingBadge />
            <UploadDialog />
            <div className="flex items-center gap-2.5">
              <span className="grid size-8 place-items-center rounded-full bg-primary text-xs font-semibold text-primary-foreground">
                LK
              </span>
              <span className="text-xs text-muted-foreground group-data-[collapsible=icon]:hidden">
                LK
              </span>
            </div>
          </div>
        </SidebarFooter>
        <SidebarRail />
      </Sidebar>
      <SidebarInset>
        <div className="flex items-center gap-2 p-2 md:hidden">
          <SidebarTrigger />
        </div>
        <div className="mx-auto w-full max-w-[1400px] p-6">{children}</div>
      </SidebarInset>
    </SidebarProvider>
  );
}
```
